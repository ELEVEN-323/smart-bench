## 〇、一句话说明我们要做的东西

一台 **"小型路灯杆为中轴 + 双侧差异化长椅"** 的社区级 AI 微服务站：

- 一根**小型路灯杆**从长椅中部立起，杆正面一块 **32 寸触控屏**，顶端 **LED 灯头 + 太阳能板**；
- 长椅**左右两半不一样**——**左侧普通长椅**（标准高度），**右侧老年人人体工学长椅**（略高座面、略浅坐深、高靠背、助起身扶手、拐杖卡槽、可拆坐垫）；
- 杆体上集成**SOS、AED、灭火弹、急救包、共享充电宝/雨伞**等应急与便民功能。

> 一句话形象：**一根会照明的杆，撑起"普通的一半 + 更照顾老人的一半"。**

---

## 一、三条底线（动笔前先记住）

| # | 底线 | 具体含义 |
|---|------|----------|
| 1 | **只做外观** | 不做内部机械结构：不做走线、电路板、螺丝孔、伸缩机构、储能电池内部。外观件"看起来合理、厚度说得通"即可，**不需要真的能装配**。 |
| 2 | **差异化是主角** | 左右两半长椅**必须一眼看出不同**：普通侧标准、适老侧明显更"照顾人"（更高、更浅、更靠背、更亮边）。这是本产品最大的设计辨识度。 |
| 3 | **一体化** | 座椅、杆体、屏幕、灯、舱门是**一台设备**，不是"椅子旁边放根杆"。**杆体是脊柱**，一切都依附于它。 |

---

## 二、外观意向（Design Brief）

- **气质**：社区里的"驿站 + 路灯"二合一，第一眼要让人觉得**安全、可坐、不复杂**。
- **体量**：杆体**小型**（总高约 4m，比常规路灯矮），长椅低矮敦实，**上轻下重**，看着稳。
- **线条**：直筒杆 + 大圆角，扶手和靠背做少量柔和曲面；不要尖锐折角、异形镂空。
- **色彩**：暖木色主导（≥40%），浅灰金属做结构与杆体，深灰做屏框。
  - **红色只给应急件**（SOS / AED / 灭火弹），保证"一眼找到救命的东西"；
  - **适老侧用明黄高对比边缘条**，让老人看清"该坐哪、边界在哪"。
- **差异化**：普通侧干净利落；适老侧功能件更多、视觉上更"被照顾"。

## 四、关键尺寸与硬约束

**建模单位：毫米（mm）**，用 Rhino 的 Millimeters 模板，**1 单位 = 1 mm**（硬约束）。

### 4.1 共用尺寸（自地面起算）

| 项目 | 尺寸 | 性质 | 说明 |
|------|------|------|------|
| 杆体总高（灯头顶） | **4000** | 硬约束 ±100 | "小型"路灯杆，比常规 6~8m 路灯矮 |
| 灯头 | 长 900，向座椅前方挑出 600~700 | 建议 | 覆盖座位与人行道 |
| 太阳能板 | 约 900×400，倾斜 15°~30° | 建议 | 置于灯头顶面，朝南 |
| 触控屏中心高 | **1200** | 硬约束 | 坐姿眼高与站姿均可及；屏可略下俯 5°~10° |
| 触控屏 | 可视区 400×710，外框 460×790 | 建议 | 适老：大字号、高对比 |
| 摄像头中心高 | 1550~1650 | 建议 | 屏幕上方，下俯 15°~25°，配 ≥90° 广角 |
| 立柱截面 | 220~280 见方（取 240） | 建议 | 中柱连接段宽 280 |
| 座面区总长 | **1460** | 硬约束 ±60 | = 普通 560 + 连接段 280 + 适老 620 |
| 含扶手总长 | 1750 | 建议 | 两侧扶手最外缘间距 |
| 地面裙座高 | 350~400 | 建议 | 立柱落地收口，**禁止做高脚踏** |

### 4.2 左右两半的差异（这是重点 ⭐）

| 项目 | 普通侧（左） | 适老侧（右） | 设计意图 |
|------|-------------|-------------|----------|
| 座面高 | 430 | **450**（含 20~40 坐垫） | 略高，起身省力 |
| 坐深 | 450 | **420** | 略浅，腿短够得着、起身易 |
| 靠背高（座面以上） | 400 | **500** | 高靠背，撑住腰背 |
| 扶手 | 标准扶手 | **助起身扶手**（略高、加粗、防滑） | 借力起身 |
| 扶手顶高 | ≈670 | ≈**690** | — |
| 座面净宽 | 560 | **620** | 适老侧更宽，放拐杖/坐垫 |
| 专属件 | — | 拐杖卡槽、可拆洗坐垫、明黄高对比边缘、低位照明、加热/通风格栅、SOS（主） | 见元件清单 |

> 除标注"硬约束"的项，其余为**建议值**，可在保证整体关系不变的前提下微调比例，不用逐 mm 对齐。

## 五、元件位置清单（建模时逐个落位）

### 5.1 杆体件（共用）

| # | 元件 | 位置 | 朝向 / 尺寸 | 建模要点 |
|---|------|------|-------------|----------|
| 1 | **32" 触控屏** | 杆体正面，中心高 1200 | 可视区 400×710，外框 460×790 | 屏面比杆面内凹 3~5；哑光黑框；上方 30~50 出檐遮光挡雨 |

| 7 | **AED 舱** | 杆体正面、屏幕正下方，高 350~780 | 门板 ~200 宽 | 红色门板 + "AED"标 + 徒手拉手，醒目 |
| 8 | **灭火弹舱** | 杆体左侧面，高 500~900 | 小舱门 | 红色，与 AED 呼应 |
| 9 | **急救包舱** | 杆体右侧面（朝适老侧），高 500~900 | 小舱门 | 急救十字标 |
| 10 | **共享充电宝·雨伞舱** | 杆体背面，高 600~1200 | 舱口 + 扫码区 | 出租仓口，带小显示屏位 |
| 11 | **状态灯带** | 杆体竖向细灯带 | 宽 10~20 | 空闲=暖白呼吸 / 使用中=常亮 / 呼叫中=红闪 |
| 12 | **二维码牌** | 杆体侧面 / 屏框 | 约 80×80 内凹 | 站着扫、坐着扫都顺 |

### 5.2 座椅件（左右两半）

| # | 元件 | 位置 | 备注 |
|---|------|------|------|
| 13 | **SOS 物理键** | **适老侧扶手前端顶面（主）** + 普通侧扶手前端（对称） | Φ45~50，凸起 3~5，外圈防误触环 + 盲文点；红色 |
| 14 | **拐杖卡槽** | 适老侧，扶手与靠背交界处 | 竖向半圆/圆槽，内径 40~50，从座面到扶手，挂杖不滑落 |
| 15 | **可拆洗坐垫** | 适老侧座面 | 厚 20~40，四角/两侧提手或分缝，比硬座面略凸 |
| 16 | **高对比边缘** | 适老侧座面/扶手/靠背顶边 | 8~15mm 宽**明黄**条，帮老人看清边界 |
| 17 | **低位照明** | 适老侧座面下方 + 扶手底部导光条 + 杆底一圈 | 夜间指引"这里能坐"，暖光 |
| 18 | **助起身扶手** | 适老侧 | 略高、加粗、防滑纹 |
| 19 | **USB 充电（A+C）** | 每侧扶手外侧面，高 600~650 | 内凹 ≥8，带防水翻盖，**不朝上开孔** |

## 六、材质与配色

| 部位 | 建议材质 | 参考色 | 表面处理 |
|------|----------|--------|----------|
| 座面、靠背、扶手木质部分 | 户外防腐木 / 仿木铝型材 | 暖橡木 **#C08A5E** | 哑光，可见木纹 |
| 杆体、灯头、结构件 | 铝合金 / 钣金 | 浅灰 **#C9CDD2** | 细砂纹静电喷涂 |
| 屏幕外框、面板、格栅 | 工程塑料 / 铝 | 深灰 **#2B2F33** | 哑光，防指纹 |
| SOS / AED / 灭火弹 | 硅胶 + PC | 红 **#D64541** | 防滑网点 |
| **高对比边缘条** | 硅胶/耐磨漆 | 明黄 **#FFD23F** | 适老侧专属 |
| 太阳能板 | 光伏玻璃 | 深蓝黑 **#1E2A38** | 亚光 |
| 灯头出光面 / 导光条 | 乳白 PC | 暖白 **#F2EFE9** | 半透柔光 |
| 低位照明 | 半透明 PC | 暖光 **#F5C97B** | 发光均匀 |

**配色规则**

1. 木色是主角（≥40%）；金属和深灰是配角。
2. **红色只给应急件**（SOS / AED / 灭火弹），全设备红色面积 < 5%。
3. **明黄只给适老侧高对比边缘**，普通侧不要出现，否则"差异化"被稀释。
4. 所有外露边**必须倒圆角**：常规 R3~R8，扶手抓握处 R15~R20，SOS 区 R5+。

## 七、Rhino 8 建模约定

### 7.1 图层与命名（请严格遵守，后面要分件导出）

```
POLE_立柱        LIGHT_灯头        SOLAR_太阳能板   SCREEN_屏幕
CAMERA_摄像头    MIC_麦克风        SPEAKER_扬声器   STATUS_灯带
AED_AED舱        FIRE_灭火弹舱     FIRSTAID_急救包  SHARE_共享舱
SEAT_座面        BACK_靠背         ARMREST_扶手     CUSHION_坐垫
CANE_拐杖卡槽    BUTTON_按键       USB_接口         BASE_裙座
PANEL_面板件     DETAIL_细节件     HIDDEN_隐藏件
```

### 7.2 建模手法建议

- **先体量后细节**：先搭出"杆 + 左右两半长椅"的整体比例，对照第三节布局图确认位置，再抠造型。
- **曲面用 SubD 起草**：扶手、靠背这类柔性曲面用 SubD 快速推敲，满意后转 NURBS 精修倒角。
- **每个部件独立封闭实体**（各自 Join 成 closed polysurface），方便分件导出 `.glb` 与出爆炸图。
- **做一半镜像一半**：普通侧与适老侧的**共用件**（杆体、灯头、太阳能、屏）可镜像；**差异化件**（座面、靠背、扶手、坐垫、拐杖槽）左右分开建模。
- **检查两点**：布尔前 `ShowEdges` 查裸边；导出前查 <2mm 薄面、自交曲面。
- **存 Rhino 7 兼容格式**，防队友版本不同。

### 7.3 明确不要做的事

- ❌ 内部机械结构、开合机构、滑轨、铰链、舱门内部
- ❌ 螺丝、螺栓、铆钉、焊缝写实建模
- ❌ 走线、电路板、电池仓内部、加热片、雷达内部
- ❌ 屏幕贴写实 UI 截图当材质（后面代码组渲染真实界面）
- ❌ 为炫技做异形镂空、尖锐造型、超工艺薄壁

## 八、交付物与导出要求

| 交付物 | 格式 | 要求 |
|--------|------|------|
| 源文件 | `.3dm` | 图层命名符合 7.1，存 Rhino 7 兼容 |
| **3D 模型** | **`.glb`** | **单文件 < 5MB**，三角面 < 150k，网页 360° 展示 |
| 三视图 | PNG | 正视 / 侧视（适老侧）/ 俯视 + 轴测，**1920px 宽**，白底，标关键尺寸 |
| 渲染图 | PNG | 2~3 张：日景、夜景（灯光+低位照明）、适老侧细节特写 |
| 材质色板 | PNG / 文字 | 色值 + 材质说明，供前端主题取色 |

**`.glb` 导出注意**（Rhino 8：另存为 → glTF / `.glb`）

1. **单位换算**：glTF 以**米**为单位，Rhino 是 mm，导出缩放 **0.001**，否则网页放大 1000 倍。
2. 材质用 **PBR 基础色**，不用程序贴图、多层材质、透明折射。
3. 分件命名保留（= 图层名），代码组靠它做点击高亮。
4. 导出前删隐藏件、参考线、辅助曲面。

## 九、验收清单

- [ ] 单位 mm，实际尺寸与第四节一致（`Length` / `Volume` 抽查）
- [ ] 硬约束满足：杆体总高 4000、屏幕中心 1200、座面区总长 1460
- [ ] **左右两半一眼能看出差异化**（普通 430/450/400 vs 适老 450/420/500）
- [ ] 20 个元件都在位，位置与本文件一致
- [ ] 适老侧专属件齐全：拐杖卡槽、坐垫、明黄边、低位照明、助起身扶手、SOS
- [ ] 四个舱门（AED/灭火弹/急救包/共享）在杆体四周分布、位置正确
- [ ] 所有外露边已倒圆角，无尖角
- [ ] 部件各自封闭实体，图层命名规范

- [ ] `.glb` < 5MB，单位换算正确，导入网页后与人体比例正常

## 十、待定项（需要设计同学反馈）

1. **触控屏要不要做"下俯 5°~10°"的倾斜支架**，还是完全贴合杆面？
2. **拐杖卡槽放扶手内侧还是靠背外侧**更顺手？（建议靠扶手与靠背交界处）
3. **适老侧坐垫的颜色**：继续用木色，还是做一块浅色/易识别的独立色？
4. **共享充电宝·雨伞舱**要不要在背面做一块小屏显示"可借数量"？
5. **普通侧要不要也放低位照明**，还是只在适老侧（当前方案只在适老侧）？

## 十一、沟通约定

- 建模中**任何拿不准的位置关系随时问**，不要自己猜一路做下去。
- 提问建议带：**截图/视角 + 问题 + 你的倾向方案**，一轮定。
- 造型曲线、比例微调、表面细节、材质表现这些**不需要问我**，属于你们专业范围。
- 需要我配合：位置关系、元件朝向、尺寸约束、某个功能到底"要不要露出来"。
